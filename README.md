## 🎬 Ye Userbot Kaise Kaam Karta Hai?

<div align="center">

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  📱 Aapki Telegram App                                      │
│         │                                                   │
│         ▼                                                   │
│  ┌──────────────┐                                           │
│  │  Telegram    │  ← Aapka account (session string)         │
│  │  Servers     │                                           │
│  └──────┬───────┘                                           │
│         │ MTProto Protocol                                  │
│         ▼                                                   │
│  ┌──────────────────────────────────────────────┐           │
│  │  🤖 Ultimate Userbot (aapka code)             │           │
│  │                                              │           │
│  │  ┌────────────────────────────────────┐    │           │
│  │  │  🔄 Plugin Manager                 │    │           │
│  │  │     ├─ Scan imports                │    │           │
│  │  │     ├─ Install missing deps        │    │           │
│  │  │     └─ Register handlers           │    │           │
│  │  └────────────────────────────────────┘    │           │
│  │                                              │           │
│  │  ┌────────────────────────────────────┐    │           │
│  │  │  🔐 Session Vault                  │    │           │
│  │  │     └─ Decrypt SESSION_STRING      │    │           │
│  │  └────────────────────────────────────┘    │           │
│  │                                              │           │
│  │  ┌────────────────────────────────────┐    │           │
│  │  │  📦 Modules (40+)                  │    │           │
│  │  │     ├─ Commands                    │    │           │
│  │  │     ├─ AI features                 │    │           │
│  │  │     └─ Automation                  │    │           │
│  │  └────────────────────────────────────┘    │           │
│  └──────────────────────────────────────────────┘           │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

</div>

**Simple explanation:**

1. **Aapka account** Telegram servers pe login hota hai (session string se)
2. **Userbot** aapke account pe chalta hai (jaise aap Telegram app use karte ho)
3. **Modules** har command handle karte hain (`.ping`, `.ai`, `.yt`, etc.)
4. **Jab aap command bhejte ho**, userbot wahi kaam karta hai jo aap manually karte

**Ye bot kisi aur ka nahi hai — ye aapka hi account hai, bas automated.**

```bash
cd ~
git clone https://github.com/YOUR_USERNAME/myuserbot.git
cd myuserbot
```

**Step 7: Configure**

```bash
nano .env                           # API_ID, API_HASH, OWNER_ID, VAULT_KEY
```

**Step 8: Session**

```bash
python gen_session.py --name main --yes
```

**Step 9: Run in background**

```bash
tmux new -s bot
python main.py
# Detach: Ctrl+B, then D
# Reattach: tmux attach -t bot
```

**Step 10: Auto-start on boot**

```bash
mkdir -p ~/.termux/boot
nano ~/.termux/boot/start-bot.sh
```

Paste:
```bash
#!/data/data/com.termux/files/usr/bin/sh
termux-wake-lock
cd ~/myuserbot
nohup python main.py > bot.log 2>&1 &
```

```bash
chmod +x ~/.termux/boot/start-bot.sh
```

Install [Termux:Boot](https://f-droid.org/packages/com.termux.boot/) — phir phone restart pe auto-start.

## ⚙️ Configuration Samjho

### `.env` File Kya Hai?

Ye ek **secret file** hai jisme aapke passwords aur keys hote hain. **Ise kabhi kisi ko mat do.**

```env
# ══════════════════════════════════════════════════
#  🔑 TELEGRAM — Required (my.telegram.org se lo)
# ══════════════════════════════════════════════════
API_ID=123456
API_HASH=your_api_hash_here
SESSION_STRING=                    # gen_session.py baad me bharega
OWNER_ID=123456789                 # @userinfobot se lo

# ══════════════════════════════════════════════════
#  🤖 BOT SETTINGS
# ══════════════════════════════════════════════════
BOT_NAME=Ultimate Userbot
PREFIX=.                           # Command prefix (.help, !help)

# ══════════════════════════════════════════════════
#  🔐 SECURITY — Recommended
# ══════════════════════════════════════════════════
VAULT_KEY=                         # 32+ random chars

# ══════════════════════════════════════════════════
#  📊 DASHBOARD — Optional
# ══════════════════════════════════════════════════
DASHBOARD_ENABLED=false
DASHBOARD_PORT=8080

# ══════════════════════════════════════════════════
#  🤖 AI APIs — Optional
# ══════════════════════════════════════════════════
OPENAI_API_KEY=                    # platform.openai.com
GEMINI_API_KEY=                    # aistudio.google.com
GROQ_API_KEY=                      # console.groq.com
```

### `VAULT_KEY` Generate Karo

```bash
python -c "import base64, os; print(base64.urlsafe_b64encode(os.urandom(32)).decode())"
```

Output example:
```
dGhpcyBpcyBhIHN1cGVyIHNlY3VyZSBrZXkgZm9yIHlvdQ==
```

Isko `.env` me paste karo — `VAULT_KEY=` ke aage.

## 🔐 Security — Zaroor Padho

### 🎯 Session Vault Kaise Kaam Karta Hai?

```
Aapki Session String
       │
       ▼
┌──────────────────┐
│  SHA256(VAULT_KEY) │  ← Key derivation
└────────┬─────────┘
         │
         ▼
┌──────────────────┐
│  Fernet (AES-128) │  ← Encryption
└────────┬─────────┘
         │
         ▼
   gAAAAAB...xyz        ← Encrypted (safe to store)
```

**Agar koi ye encrypted string chura bhi le, bina `VAULT_KEY` ke kuch nahi kar sakta.**

### 🚨 Kabhi Mat Karo

| ❌ Galat | ✅ Sahi |
|---------|---------|
| Session string screenshot bhejna | Sirf `.env` me rakho |
| `.env` GitHub pe push | `.gitignore` me daalo |
| Random website se session | Sirf `gen_session.py` use karo |
| Session kisi dost ko dena | Bilkul nahi |
| Main account pe bot chalana | Secondary account |

### 🛡️ Safety Checklist

- [ ] `VAULT_KEY` set kiya `.env` me
- [ ] `.env` `.gitignore` me hai
- [ ] `chmod 600 .env` chalaya
- [ ] 2FA enable hai Telegram pe
- [ ] Secondary account use kar rahe ho
- [ ] Session string kabhi share nahi ki
- [ ] 6 mahine me session rotate karoge

## 🐛 Errors Fix Karo

<details>
<summary><b>❌ <code>platform android is not supported</code></b></summary>

**Kyun:** Termux me kuch libraries build nahi hoti.

**Fix:**
```bash
pkg install python-psutil python-lxml
```

</details>

<details>
<summary><b>❌ <code>externally-managed-environment</code></b></summary>

**Kyun:** Termux PEP 668 use karta hai.

**Fix:**
```bash
pip install --break-system-packages <package>
```

</details>

<details>
<summary><b>❌ <code>RuntimeError: no current event loop</code></b></summary>

**Kyun:** Python 3.14 ne `get_event_loop()` ka behavior badla.

**Fix:** File ke top pe ye add karo:
```python
import asyncio
try:
    asyncio.get_event_loop()
except RuntimeError:
    asyncio.set_event_loop(asyncio.new_event_loop())
```

</details>

<details>
<summary><b>❌ <code>AuthKeyUnregistered</code></b></summary>

**Kyun:** Session revoke ho gayi.

**Fix:**
```bash
python gen_session.py --name main --yes
```

</details>

<details>
<summary><b>❌ <code>FloodWait</code></b></summary>

**Kyun:** Telegram rate limit.

**Fix:** Bata diye gaye seconds **wait karo**. Retry mat karo turant.

</details>

<details>
<summary><b>❌ Termux me screen off pe band ho jaata</b></summary>

**Fix:**
```bash
termux-wake-lock
```

Android settings → Apps → Termux → Battery → **Unrestricted**.

</details>

<details>
<summary><b>❌ <code>SessionPasswordNeeded</code></b></summary>

**Kyun:** Aapke account me 2FA on hai.

**Fix:** `gen_session.py` 2FA password maangega — wo daalo.

</details>

<details>
<summary><b>❌ Dashboard open nahi hota</b></summary>

**Fix 1:** FastAPI install karo:
```bash
pip install --break-system-packages fastapi uvicorn
```

**Fix 2:** Ya `.env` me disable karo:
```env
DASHBOARD_ENABLED=false
```

</details>

from helpers import cmd

def register(app):
